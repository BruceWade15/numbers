# Singing Numbers

Turn any number sequence into music. Each digit from 0 to 9 is a note. Three modes: Compose, Live Play with a sustain pedal (hold Space), and Preloaded tunes. Eight instruments are synthesised in the browser with the Web Audio API.

**Live:** https://brucewade15.github.io/numbers/

## How it works

- One self contained `index.html`. There is no build step and nothing to install.
- To run it on your own computer, open `index.html` in a browser.
- Hosted on GitHub Pages from this repo, so a push to the main branch updates the live site.
